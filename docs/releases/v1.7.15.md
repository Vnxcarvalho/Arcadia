## Arcadia 1.7.15

Fixes for signing in with GitHub:

- **First-run setup uses your GitHub account.** "Use my GitHub account" signs in through GitHub and
  fills your name and picture, instead of asking you to type your username. The same sign-in lets you
  clone your repositories later.
- **The GitHub sign-in page opens, or tells you why it did not.** The code screens show the address
  (`github.com/login/device`) so you can open it yourself, and say when the browser could not be
  opened. On Windows, links now open through the system's own handler, which reports a failure.

**Updating is optional.** If you run version 1.7.5 or later, a prompt offers this update from inside
the app: choose **Update now** to download and install it, or **Later** to keep working. If you run
1.7.4 or earlier, install this version once from the installer.

This release ships for Windows only. The complete list of changes is in
[`docs/CHANGELOG.md`](https://github.com/Vnxcarvalho/Arcadia/blob/main/docs/CHANGELOG.md).
