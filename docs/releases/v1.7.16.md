## Arcadia 1.7.16

GitHub sign-in is now done on the GitHub website:

- **No code to type.** "Open GitHub" opens github.com with the code already filled in, so you only
  confirm your account and press **Authorize**. The code stays on screen to compare with the page, and
  the plain address appears only if the browser could not be opened.
- This applies to the first-run setup ("Use my GitHub account") and to cloning your repositories.

**Updating is optional.** If you run version 1.7.5 or later, a prompt offers this update from inside
the app: choose **Update now** to download and install it, or **Later** to keep working. If you run
1.7.4 or earlier, install this version once from the installer.

This release ships for Windows only. The complete list of changes is in
[`docs/CHANGELOG.md`](https://github.com/Vnxcarvalho/Arcadia/blob/main/docs/CHANGELOG.md).
