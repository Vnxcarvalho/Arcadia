## Arcadia 1.7.13

Antigravity agent teams, and GitHub projects that work without picking a folder:

- **Antigravity teams work from Antigravity's sandbox.** The lead can open members and send them new
  tasks (`alethe-team open` and `alethe-team send`), and the terminals show up like a tmux session,
  with coloured panes and a status line. Small tasks finish much faster: the agents get the project
  folder and skip exploring the disk.
- **GitHub projects use their clone.** A project made from a GitHub link now opens its terminals in the
  clone. With no folder chosen, Arcadia keeps a shallow copy in its own folder, and removes it with the
  project unless it holds changes that were not pushed.
- **One project at a time.** A new terminal in a project that is not on screen opens that project in its
  own tab instead of joining the current view.
- Arcadia always starts on Home, clone notifications are clearer, new terminals take the keyboard, and
  empty workspaces show the Arcadia bust.
- The About card names Alan Carvalho, and the Tutorials tab and the Contribute section are gone.

**Updating is optional.** If you run version 1.7.5 or later, a prompt offers this update from inside
the app: choose **Update now** to download and install it, or **Later** to keep working. If you run
1.7.4 or earlier, install this version once from the installer.

This release ships for Windows only. The complete list of changes is in
[`docs/CHANGELOG.md`](https://github.com/Vnxcarvalho/Arcadia/blob/main/docs/CHANGELOG.md).
